# 🚀 GitHub Professional Setup Guide

This guide shows you how to optimize your GitHub repository for maximum impact.

---

## ✅ 1. Rename Repository (If Needed)

**Current**: `portfolio` ✅ (This is good!)

If you want to change it:
1. Go to: https://github.com/Amoliben/portfolio/settings
2. Click "Rename"
3. Change to: `portfolio-website` or `my-portfolio`

---

## ✅ 2. Add Topics (IMPORTANT!)

Go to: https://github.com/Amoliben/portfolio/settings

Add these topics (copy and paste):
```
nextjs
typescript
tailwindcss
portfolio
fullstack
react
web-development
frontend
backend
```

**Why?** Topics help recruiters find your project when searching for specific technologies.

---

## ✅ 3. Add Description

In repo settings, add:
```
Modern, responsive portfolio built with Next.js 14, TypeScript, and Tailwind CSS. Full-stack developer showcasing web development skills.
```

---

## ✅ 4. Add Screenshots

1. **Deploy your site first** (see DEPLOY_NOW.md)
2. Take screenshots of your portfolio:
   - Desktop view
   - Mobile view
   - Lighthouse scores

3. Create a folder: `public/screenshots/`
4. Add images there
5. Update README.md to reference them:

```markdown
## 📸 Preview

![Desktop View](public/screenshots/desktop.png)
![Mobile View](public/screenshots/mobile.png)
```

---

## ✅ 5. Make Repo Public

Ensure your repo is public:
- Go to: https://github.com/Amoliben/portfolio/settings
- Scroll to "Danger Zone"
- Make sure "Make this repository public" is set (or already is public)

---

## ✅ 6. Pin Important Repos

On your GitHub profile (https://github.com/Amoliben):
1. Click "Customize your pins"
2. Pin this `portfolio` repo
3. This shows at the top of your profile
