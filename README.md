## 🚀 Quick Start

```bash
# Clone repository
git clone https://github.com/Amoliben/portfolio.git
cd portfolio

# Install dependencies
npm install

# Run development server
npm run dev
```

Visit `http://localhost:3000`

---

## 📦 Build for Production

```bash
# Build
npm run build

# Start production server
npm start
```
